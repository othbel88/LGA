# Le Grand Alcazar – nouveau site

Site statique multilingue (fr, en, es, it, de, ar, zh, ko, ru) du Riad Le Grand Alcazar, Fès.
Le contenu de ce dépôt est le site prêt à être mis en ligne (hébergement PHP/Apache, ex. OVHcloud).

- `api/` : formulaires de contact et d'inscription (PHP)
- `.htaccess` : redirections et réglages Apache
- `suites-chambres-1/` : pages des suites et chambres
- Test local : `python3 -m http.server 8000`
